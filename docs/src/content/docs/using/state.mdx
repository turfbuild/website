Three tools read what a workspace holds and change nothing: `show`, `output` and `state_list`. None of
them plans. Two tools edit state at once: `taint` marks an instance for replacement on the next `up`,
and `untaint` clears the mark. Turf™ reads the state from the engine's records of the workspace.

## How it works

**`show`** prints a plan or the state as OpenTofu™'s machine-readable document (`tofu show -json`):

- a round's plan (the default): the round waiting at its approval point, or else the latest, or any
  round by `convergence_id` and `round`. It is the document the engine captured as the round sealed,
  so it reads the same after the round applies, for as long as the engine keeps the round;
- a planfile's document, by `planfile`;
- the workspace's state, with `what: "state"`.

**`output`** reads the root output values the last apply recorded (`tofu output -json`), all of them
or one by `name`. A module's outputs are not kept: to keep one, the configuration exposes it as a root
output.

**`state_list`** lists the resources in state (`tofu state list`): one row per instance in address
order, with its provider, schema version, taint, dependencies and identity, plus the root outputs.
`include_values` adds each resource's attributes.

**Sensitive values** print as `__cty_sensitive__` unless `show_sensitive` is set. Set it only when the
secret is needed: it enters the conversation.

**`taint` and `untaint`** are state edits, made at once, with no plan and no approval. `taint` marks
instances so the next `up` plans each one destroyed and created again (`replace_because_tainted`).
`untaint` clears the mark, so the next `up` plans them as their configuration says. To replace
something without editing state, use `plan`'s `replace` in an `up` instead: it replaces in that round
only. Both edits need a server at the `full` tier, and a `taint` makes any planfile on the workspace
stale.

## Arguments

| Tool | Argument | Meaning |
|---|---|---|
| `show` | `what` | `plan` (default) or `state`. |
| | `convergence_id` | For a plan: the run (default: the one holding the workspace). |
| | `round` | For a plan: the round (default: the one at its approval point, else the latest). |
| | `planfile` | For a plan: a planfile's ref; `convergence_id` and `round` are then not read. |
| | `show_sensitive` | Print sensitive values in the clear. A plan read so is the document `plan.digest` hashes. |
| `output` | `name` | One output (default: every output). |
| | `show_sensitive` | Print a sensitive output's value. |
| `state_list` | `include_values` | Include each resource's attribute values. |
| | `show_sensitive` | Print sensitive values in the clear. |
| `taint`, `untaint` | `addrs` | Resource instance addresses (`aws_instance.web`, `module.m.aws_instance.x[0]`). |

Every one also takes `workspace_alias`; omit it for the default workspace.
