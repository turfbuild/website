<Since soon />

Turf™-minted identity tokens for providers are coming soon. The engine issues each round's providers a short-lived
token. Its claims name the run: the workspace's `lineage`, its `phase` (`plan` or `apply`), and the like. Your cloud trusts Turf's issuer through OIDC federation, in the manner of Terraform®
Cloud's workload identity tokens.

No static key sits in `turf.env` or in a Secret. A cloud role can admit only an apply, or only one
workspace. This is about identity that Turf mints, not the engine pod's own identity.
