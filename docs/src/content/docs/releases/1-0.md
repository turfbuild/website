Released 2026-10-19.

Turf™ 1.0 is here. Point your AI agent at an ordinary Terraform® configuration — any provider, any module from the registry — and Turf plans it, shows you the plan, and applies only what you approve.

Turf is free for noncommercial use under the PolyForm Noncommercial License 1.0.0. Commercial use, including a company's internal use, needs a license, and companies can evaluate Turf free for 60 days: https://turf.build/licensing. The `turf` CLI is open source (MPL-2.0).

## What's new in 1.0

- **Work with the agent you already use.** Register Turf with Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI or VS Code in one command, and ask it to deploy, change or tear down your infrastructure. In Claude Code and Claude Desktop it runs on your Claude subscription, with no model API key, and `/turf:guide`, `/turf:up` and `/turf:destroy` are slash commands.
- **Rollouts that wait for you.** Turf now runs a local engine in the background, started at login. A rollout keeps its place when you close your agent or terminal, so a plan waiting for your approval is still there when you come back.
- **You approve exactly what you saw.** Turf stops before every change with the plan. Approving applies that plan and nothing else. If the configuration's files change after the plan was made, the plan is not applied. Run it again to get a fresh plan.
- **Plain Terraform, all the way through.** Your configuration is ordinary `.tf` files you can read, review and commit. `init` writes the dependency lock file as `terraform init` does, and state encryption is configured in your own `encryption` block.
- **Credentials as you already keep them.** Providers pick up `~/.aws/config`, `~/.kube/config` and other credential files. With [mise](https://mise.jdx.dev), each configuration gets its own environment, for example a per-project `AWS_PROFILE`.
- **A guided tour.** `/guide` (or asking your agent for one) walks through a real use case on a ready-made example.

## Upgrading from 0.17

1.0 is a new foundation, not a drop-in upgrade:

- The local engine needs `restate-server`, which Homebrew installs with Turf. Start the engine once with `brew services start turf`.
- Turf works directly on your `.tf` files. The 0.x "plot" files are no longer read.
- Agents and scripts that called the 0.x tools by name need updating. The CLI and the slash commands are already up to date.

## Telemetry

Turf now sends anonymous usage telemetry by default: the version, the platform, counts of resources, changes and runs, and an anonymous installation id. It never sends resource contents, credentials, state, or variable values or names. Turn it off with `turf telemetry off`, then `brew services restart turf`. Homebrew's analytics opt-out turns it off too, as does `DO_NOT_TRACK=1` in `~/.homebrew/services/turf.env` (the service doesn't see your shell's environment). Details: https://turf.build/telemetry.

## Install

```sh
brew install restatedev/tap/restate-server turfbuild/tap/turf
brew services start turf
```

Then connect your agent:

```sh
npx add-mcp@2 "$(command -v turf-mcp-server)" --name turf -g
# or, for Claude Code:  claude mcp add turf --scope user -- turf-mcp-server
```

Or use the Turf CLI with your own model API key: `turf -C ./path/to/config up`.

Each tarball carries four binaries, `turf`, `turf-mcp-server`, `turf-engine` and `turf-builtin-provider`, which go on your `PATH` side by side. Setup for each agent: https://github.com/turfbuild#connect-your-agent.

## Container image
```sh
docker pull ghcr.io/turfbuild/turf-mcp-server:v1.0.0   # also :latest
```

## Verify your download

```bash
ID='^https://github.com/turfbuild/turf-mcp-server/'
ISS=https://token.actions.githubusercontent.com

# CLI — provenance + SBOM
gh attestation verify turf --repo turfbuild/turf

# Server binary — cosign (bundle ships on this release);
# turf-engine and turf-builtin-provider verify the same way, with their own bundles
cosign verify-blob-attestation --type slsaprovenance1 \
  --bundle turf-mcp-server-<os>_<arch>.provenance.sigstore.json \
  --certificate-identity-regexp "$ID" --certificate-oidc-issuer "$ISS" \
  turf-mcp-server-<os>_<arch>

# Container image
cosign verify ghcr.io/turfbuild/turf-mcp-server:v1.0.0 \
  --certificate-identity-regexp "$ID" --certificate-oidc-issuer "$ISS"
```

`checksums.txt` is the no-tooling fallback.
