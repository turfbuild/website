Turf™ 1.5 is available now. From this release Turf ships under a new license, the Turf Community Edition License 1.0, and asks you to accept it once.

## The Turf Community Edition License

**Who uses Turf free.** Turf is free for individuals, education, non-commercial open source projects and small businesses, within the Community limits. Government and larger organizations need a commercial license. Who that covers, and the limits themselves, are in plain words at https://turf.build/licensing/; the binding text is at https://turf.build/license/v1/.

**Evaluate without signing anything.** Any organization, government included, can evaluate Turf in non-production for 30 days from its first use. The free 60-day pilot on the Common Paper Pilot Agreement stays, for a longer or supported trial.

**The same binary, and no license key.** Every build is the same binary with the same features. There is no license key, no license server and no update check. The `turf` CLI's source stays open under MPL-2.0.

**Accepted once, by you.** The terms are a public cover page on the Common Paper Software License Agreement Standard Terms 1.1, and each release names the version of the terms that governs it. You accept them by an act of your own:

- run `turf license accept`, which records the acceptance in `~/.turf/license.json`;
- or type `yes` when the `turf` CLI asks, on its first run in a terminal;
- or set `TURF_ACCEPT_EULA=yes` where no one is there to answer: a container, a CI job, a Kubernetes® pod, an MCP client's configuration. Setting it accepts the terms at https://turf.build/license/v1/.

Every release archive carries the terms as `LICENSE`, the standard terms as `STANDARD-TERMS.md` and the third-party notices as `NOTICE`. `turf --version` prints the license in two lines.

**Telemetry.** With telemetry on, the engine's `engine.start` event gains two fields: `terms_version` and `terms_accepted_via`. Nothing else about your acceptance is sent, and nothing at all with telemetry off. The field list is at https://turf.build/telemetry/.

Releases 1.0 to 1.4 keep the license they shipped with.

## Before you upgrade

- **1.5 does nothing until the license terms are accepted.** Read them at https://turf.build/license/v1/ before you upgrade.
- **Check whether your use is free under the new terms**: https://turf.build/licensing/. From 1.5 a small business uses Turf free within the Community limits, and government needs a commercial license.
- **In a cluster, acceptance is an `env` entry in each Turf container**: the engine, the server and the console. Add it to your manifests before 1.5 rolls out ([Minimal manifests](/docs/cluster/manifests/#the-license)). The image does not set it for you.
- **A CI job that runs `turf` needs `TURF_ACCEPT_EULA=yes` in its environment**, or it exits with status 77. Setting it accepts the terms at https://turf.build/license/v1/.

## Upgrading from 1.4

```
brew upgrade turfbuild/tap/turf
brew services restart turf
turf license accept
```

Then restart your agent's MCP connection.

Until you run `turf license accept`, this is what a 1.4 user sees after the upgrade:

- **The engine service is up and has started nothing.** `turf-mcp-server engine status` says `awaiting license`. The service checks every 2 seconds and starts the engine within seconds of your acceptance, with no second restart.
- **Your agent's calls return the license notice.** The MCP server starts and lists its tools, and every tool call returns the notice with a note asking the agent to have you read the terms and confirm. After `turf license accept` the next call runs; the server needs no restart.
- **The `turf` CLI asks.** On a terminal it prints the notice and waits for `yes`. With no terminal, as in CI, it prints the notice and exits with status 77.
- **In a cluster, the engine and the console exit with status 77**, and their pods go to `CrashLoopBackOff` until the `env` entry is there. The server starts, and every call returns the notice.

A variable set in your shell or in an MCP client's configuration does not reach the Homebrew service. The record `turf license accept` writes does, and so does `~/.homebrew/services/turf.env`. Each case is in [Accept the license](/docs/start/install/#accept-the-license).
