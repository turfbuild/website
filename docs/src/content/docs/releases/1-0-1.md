Released 2026-10-21.

Turf™ 1.0.1 is a fix release for 1.0. Turf 1.0 refused a configuration that puts `depends_on` on an output, and 1.0.1 runs it. 1.0.1 is also built with Go 1.26.10, which refuses certificates issued through the eight eMudhra CAs whose keys were compromised this month. If you run 1.0.0, upgrade.

Turf is free for noncommercial use under the PolyForm Noncommercial License 1.0.0. Commercial use, including a company's internal use, needs a license, and companies can evaluate Turf free for 60 days: https://turf.build/licensing. The `turf` CLI is open source (MPL-2.0).

## What's fixed in 1.0.1

- **`depends_on` on an output works.** Turf 1.0 refused the plan of any configuration with an `output` block that declares `depends_on`. That ruled out the module bundles NVIDIA AICR's Terraform® deployer generates. Turf now honours it as Terraform does. Anything that reads the output waits for what the output depends on, and the output is written once those land. If what it depends on has to wait for a later round, the output waits with it.
- **`depends_on` can name one output of a module.** `depends_on = [module.network.vpc_id]` now waits for what that output depends on, not for everything in the module. Turf 1.0 refused it.
- **`depends_on` refuses a resource attribute, as Terraform does.** An entry such as `depends_on = [aws_instance.web.id]` used to be read as the whole resource. Turf now refuses it, as Terraform and OpenTofu™ do. Name the resource itself: `depends_on = [aws_instance.web]`.
- **Built with Go 1.26.10, which refuses the compromised eMudhra CAs.** The private keys of eight eMudhra intermediate CAs (six for TLS, two for code signing) can be computed from their public certificates. Anyone can use them to issue a certificate for any domain. Go 1.26.10 makes certificate verification reject every chain through them (GO-2026-6809, CVE-2026-111943). Every TLS connection Turf makes, including provider and module downloads, now refuses them, whatever the system trust store says.
  - **On Linux, Turf 1.0.0 is exposed.** It was built with Go 1.26.9 and accepts such a chain until the distribution's `ca-certificates` drops emSign ECC Root CA - G3. Debian and Ubuntu did so on October 20.
  - **On macOS, the system has blocked these certificates since October 19.** Upgrade there too.

## Upgrading from 1.0.0

```sh
brew upgrade turf
brew services restart turf
```

## Install

```sh
brew install restatedev/tap/restate-server turfbuild/tap/turf
brew services start turf
```

Then connect your agent:

```sh
npx add-mcp@2 "$(command -v turf-mcp-server)" --name turf -g
# or, for Claude Code:  claude mcp add turf --scope user -- turf-mcp-server
```

Or use the Turf CLI with your own model API key: `turf -C ./path/to/config up`.

Each tarball carries four binaries, `turf`, `turf-mcp-server`, `turf-engine` and `turf-builtin-provider`, which go on your `PATH` side by side. Setup for each agent: https://github.com/turfbuild#connect-your-agent.

## Container image
```sh
docker pull ghcr.io/turfbuild/turf-mcp-server:v1.0.1   # also :latest
```

The 1.0.1 image carries Alpine's `ca-certificates` of 2026-10-20, which no longer trusts emSign ECC Root CA - G3. So `git` and the provider plugins Turf runs inside it refuse the compromised eMudhra chains too, whatever Go a provider was built with. The 1.0.0 image still trusts that root: replace it with 1.0.1. Outside the image, provider plugins use the host's trust store, so keep the host's `ca-certificates` current. Red Hat's update is pending, with a workaround.

## Verify your download

```bash
ID='^https://github.com/turfbuild/turf-mcp-server/'
ISS=https://token.actions.githubusercontent.com

# CLI — provenance + SBOM
gh attestation verify turf --repo turfbuild/turf

# Server binary — cosign (bundle ships on this release);
# turf-engine and turf-builtin-provider verify the same way, with their own bundles
cosign verify-blob-attestation --type slsaprovenance1 \
  --bundle turf-mcp-server-<os>_<arch>.provenance.sigstore.json \
  --certificate-identity-regexp "$ID" --certificate-oidc-issuer "$ISS" \
  turf-mcp-server-<os>_<arch>

# Container image
cosign verify ghcr.io/turfbuild/turf-mcp-server:v1.0.1 \
  --certificate-identity-regexp "$ID" --certificate-oidc-issuer "$ISS"
```

`checksums.txt` is the no-tooling fallback.
